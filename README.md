# TelegramMiniApp
🎮 پرامپت کامل برای ساخت بازی "شکارچیان سایه"

یک ربات تلگرامی به سبک Solo Leveling

---

این پرامپت را به یک هوش مصنوعی کدنویس (مانند Claude، Cursor، یا ChatGPT) بدهید تا کل بازی را برایتان پیاده‌سازی کند.

---

📋 مشخصات کلی پروژه

یک ربات تلگرام با قابلیت Web App (Mini App) می‌خواهم که یک بازی نقش‌آفرینی آنلاین به سبک انیمه Solo Leveling باشد. بازی باید به صورت ترکیبی از منوهای متنی/دکمه‌ای در چت تلگرام (برای ۹۰٪ تعاملات) و Web App با Svelte/SvelteKit (برای بخش‌های مبارزه، جمع‌آوری مانا، فروشگاه بزرگ و بورس) کار کند. کل زیرساخت باید کاملاً رایگان با استفاده از سرویس‌های Cloudflare Workers، Cloudflare Pages، Turso Database و Upstash Redis پیاده‌سازی شود.

نام بازی: "شکارچیان سایه" (Shadow Hunters)

تکنولوژی‌های مورد استفاده:

· Backend ربات: TypeScript با کتابخانه grammy روی Cloudflare Workers
· Web App: Svelte/SvelteKit روی Cloudflare Pages
· API Server: Cloudflare Workers با TypeScript
· Database: Turso (SQLite) با Drizzle ORM
· Cache & Session: Upstash Redis
· File Storage: Cloudflare R2
· Payment: Telegram Stars
· Real-time: Cloudflare Durable Objects برای WebSocket

اصل طراحی: ۹۰٪ تعاملات با دکمه‌های تلگرامی انجام شود. Web App فقط برای بخش‌هایی باز شود که نیاز به تجربه بصری و تعاملی دارند (فایت دانجن، جمع‌آوری مانا، شاپ و بازار، بورس، کرفتینگ).

🎯 سیستم‌هایی که باید ساخته شوند:

---

۱. سیستم کاراکتر (Character System)

توضیح:
هر بازیکن با دستور /start یک کاراکتر می‌سازد. کاراکتر دارای استت‌های زیر است:

· ATK (قدرت حمله): میزان آسیب وارده به دشمن
· DEF (دفاع): کاهش آسیب دریافتی
· SPD (سرعت): تعیین نوبت حمله در فایت تیمی
· CRIT (شانس ضربه بحرانی): درصد احتمال آسیب ۲ برابر
· HEAL (بازیابی): مقدار سلامتی که می‌تواند در حین فایت بازیابی کند

بازیکن با کسب XP از دانجن‌ها لول آپ می‌شود. هر لول ۵ استت پوینت به بازیکن می‌دهد که می‌تواند بین استت‌هایش تقسیم کند. حداکثر لول ۱۰۰ است.

منوهای مورد نیاز:

· منوی پروفایل (نمایش استت‌ها، لول، XP، رنک)
· منوی تخصیص استت پوینت
· منوی تاریخچه دستاوردها

رنک‌بندی شکارچیان:

رنک عنوان مزایا
E شکارچی تازه‌کار بدون مزایا
D شکارچی کارآموز +۵٪ طلا از دانجن‌ها
C شکارچی حرفه‌ای +۱۰٪ طلا، ۱ اسلات کیف اضافه
B شکارچی کهنه‌کار +۱۵٪ طلا، اولویت در لوت تیمی
A شکارچی نخبه +۲۰٪ طلا، امکان ورود به دانجن قرمز
S شکارچی افسانه‌ای +۳۰٪ طلا، یک مهارت ویژه
National شکارچی ملی دسترسی به دانجن‌های ملی، فقط ۵ نفر در کل سرور

ارتقاء رنک بر اساس مجموع دانجن‌های تموم شده، قدرت کاراکتر و دستاوردهای خاص انجام می‌شود.

۲. سیستم دانجن (Dungeon System)

توضیح:
دانجن‌ها هسته اصلی بازی هستند. هر دانجن دارای لول (E تا S) و تعداد مشخصی موج دشمن (۳ تا ۱۰ موج) و یک باس نهایی است.

حالت‌های دانجن:

· سولو: بازیکن به تنهایی وارد می‌شود
· تیمی: لیدر تیم یک گروه می‌سازد، اعضا جوین می‌شوند، لیدر می‌تواند Kick کند یا دعوت‌ها را تأیید/رد کند. اعضا می‌توانند قبل از شروع Leave دهند. بعد از شروع، Leave = مرگ در دانجن. حداکثر ۵ نفر در تیم.

انواع دانجن:

الف) دانجن معمولی:

· لول‌بندی شده از E تا S
· دشمنان متناسب با لول دانجن
· دراپ آیتم و طلا پس از اتمام

ب) دانجن قرمز (Red Gate):

· شانس ۱-۲٪ ظاهر شدن در گیلد
· دشمنان +۱۰ لول قوی‌تر از قوی‌ترین عضو
· غیرقابل فرار - یا برنده می‌شوی یا می‌میری
· برد = یک لول کامل آپ (حتی از ۴۰ به ۴۱)
· دراپ فوق‌العاده کمیاب (مثل کیف نامحدود، آیتم اسطوره‌ای)
· فقط تیمی (حداقل ۳ نفر)

ج) دانجن مخفی (Hidden Dungeon):

· شانس ۵-۱۰٪ بعد از تموم شدن هر دانجن
· بازیکن ۳۰ ثانیه فرصت دارد تصمیم بگیرد وارد شود یا خیر (در حالت تیمی، رأی‌گیری اکثریت)
· ۵ نوع گذرگاه مخفی:
  ۱. اتاق شانس (۴۰٪): فقط مانا و گنج، بدون مبارزه
  ۲. کمین نخبگان (۳۵٪): ۲-۳ ماب نخبه، لوت ۲ برابر، بدون فرار
  ۳. هزارتوی فراموشی (۱۵٪): ۳ مسیر با انتخاب (گنج، تله ۵۰٪ آسیب، یا معما)
  ۴. اتاق کهن (۸٪): یک معمای سخت (چیستان، دنباله اعداد، رمزگشایی)، حل = آیتم افسانه‌ای یا کلید دانجن قرمز، اشتباه = از دست دادن ۱ آیتم تصادفی
  ۵. دروازه آزمایش (۲٪): چالش مرگ و زندگی

د) دروازه آزمایش (Gate of Trial):

· فقط ماهی یک بار در کل سرور ظاهر می‌شود
· فقط یک نفر می‌تواند وارد شود (اولین کسی که پیدا کند و قبول کند)
· شرط ورود: قربانی کردن تمام آیتم‌ها و طلای همراه
· ریسک: Permadeath واقعی (حتی Rebirth سایه هم نیست - کاراکتر کاملاً حذف می‌شود)
· فقط سولو

مراحل دروازه آزمایش:

1. هزارتوی سکوت: ۳ معمای منطقی/ریاضی سخت، ۲ دقیقه برای هر کدام، هر اشتباه = -۲۰٪ HP دائمی
2. آینه روح: مبارزه با کپی خود بازیکن (همان لول، استت و مهارت‌ها)
3. نگهبان دروازه (باس نهایی): ۱۰ لول بالاتر از بازیکن، ۳ مرحله با قدرت فزاینده، بدون امکان هیل بین مراحل

پیروزی = Divine Awakening:

· لول جدید: ۳۰ (یا ۲۰+ لول قبلی، هرکدام بیشتر)
· عنوان: "خداکُش" (Godslayer) با افکت طلایی روی اسم
· ۱۰۰ استت پوینت اضافه
· یک مهارت منحصر‌به‌فرد که فقط ۱ نفر در کل بازی دارد
· اسلات کیف: ۱۵ دائمی
· مقاومت ۵۰٪ به همه آسیب‌ها
· پیام جهانی (ناشناس): "یکی از شکارچیان... از دروازه آزمایش بازگشته است."

شکست:

· کاراکتر کاملاً حذف می‌شود
· نام در تالار قهرمانان فراموش‌شده ثبت می‌شود
· پیام در گیلد: "شکارچی [اسم] در جستجوی قدرت نهایی، جان خود را فدا کرد."

۳. سیستم مبارزه (Combat System)

توضیح:
مبارزه به صورت نوبتی است. بازیکن در هر نوبت یکی از گزینه‌های زیر را انتخاب می‌کند:

· 🗡️ حمله عادی: آسیب پایه بر اساس ATK
· 🔥 مهارت ویژه: آسیب بیشتر یا اثر خاص (بستگی به مهارت‌های بازیکن دارد)
· 🛡️ دفاع: کاهش ۵۰٪ آسیب دریافتی در آن نوبت
· 🧪 معجون: استفاده از آیتم مصرفی (هیل، تقویت موقت)
· 🏃 فرار: خروج از دانجن (در دانجن قرمز و بعضی مخفی‌ها غیرممکن)

نوار سلامتی (HP Bar):
با ایموجی قلب نمایش داده می‌شود:

```
❤️❤️❤️❤️❤️🤍🤍🤍🤍🤍  [50%]
```

در فایت تیمی:

· نوبت‌ها بر اساس SPD (سرعت) تعیین می‌شود
· سیستم Threat: بازیکنی که بیشترین آسیب را زده، بیشتر مورد حمله دشمن قرار می‌گیرد
· تانک‌ها (DEF بالا) مهارت "تحریک" دارند که Threat را افزایش می‌دهد

Web App فایت:

· صحنه مبارزه با انیمیشن‌های ساده (CSS animations)
· نوار HP با transition های نرم
· لاگ مبارزه (چه کسی چه آسیبی زد)
· دکمه‌های بزرگ و واکنش‌گرا
· گیف‌های کوتاه برای حملات خاص (از Cloudflare R2 لود شود)

۴. سیستم آیتم‌ها (Item System) - ۷۲۵+ آیتم

توضیح:
آیتم‌ها با سیستم Base + Prefix + Suffix ساخته می‌شوند تا تنوع بسیار بالا ایجاد شود.

آیتم‌های پایه (Base Items):
۱۰ نوع: شمشیر، خنجر، تبر، نیزه، سپر، زره، کلاه، دستکش، چکمه، عصا
هر کدام استت‌های پایه متفاوت دارند.

پیشوندها (Prefixes - عنصری):
۸ نوع:

· آتشین 🔥: +۱۰ آسیب آتش
· یخی ❄️: +۱۰ آسیب یخ، شانس کُند کردن دشمن
· برقی ⚡: +۱۰ آسیب برق، شانس استان
· سمی ☠️: +۸ آسیب سم در ۳ نوبت
· تاریک 🌑: +۱۵ آسیب (فقط برای سایه‌ها قابل استفاده)
· نورانی ✨: +۵ به همه استت‌ها
· خونین 🩸: ۵٪ Life Steal (درصدی از آسیب تبدیل به هیل)
· فرسوده 💀: -۵ قدرت، ولی شانس کریت +۱۵٪

پسوندها (Suffixes - منشأ):
۸ نوع:

· از گرگ 🐺: +۵٪ شانس کریت
· از اژدها 🐉: +۱۵٪ مقاومت آتش
· از فرشته 👼: +۱۰٪ قدرت هیل
· از شیطان 😈: +۲۰ ATK, -۱۰ DEF
· از پادشاه 👑: +۳ به همه استت‌ها
· از گورکن 💀: شانس ۵٪ زنده شدن پس از مرگ
· از معدن ⛏️: +۲۰٪ Durability
· از طبیعت 🌿: ۲٪ هیل خودکار در هر نوبت

فرمول: Base (۱۰) × Prefix (۸) × Suffix (۸) = ۶۴۰ ترکیب آیتم عادی

· ۵۰ آیتم خاص (افسانه‌ای و اسطوره‌ای)
· ۲۰ معجون مختلف
· ۱۵ کیف و اقلام مصرفی
  = ۷۲۵+ آیتم منحصر‌به‌فرد

کیفیت آیتم‌ها (Rarity):

· ⚪ معمولی (Common)
· 🔵 کمیاب (Rare)
· 🟣 حماسی (Epic)
· 🟡 افسانه‌ای (Legendary)
· 🔴 اسطوره‌ای (Mythic) - فقط ۱ تا ۵ عدد در کل سرور

سیستم Durability (سلامت آیتم):
هر آیتم یک نوار سلامت ۱۰۰ واحدی دارد:

وضعیت Durability اثر
✅ نو ۱۰۰-۸۰٪ قدرت کامل
⚠️ فرسوده ۷۹-۵۰٪ -۵٪ از قدرت کل
🔶 آسیب‌دیده ۴۹-۲۰٪ -۲۰٪ قدرت، +۱۰٪ شانس شکست در هر حمله
🔴 در حال شکستن ۱۹-۵٪ -۵۰٪ قدرت، ۳۰٪ شانس نابودی در هر حمله
💀 شکسته ۰٪ غیرقابل استفاده، فقط قابل تعمیر یا اسقاط

کاهش Durability:

· هر حمله در دانجن: ۱-۲ واحد
· باس فایت: ۳-۵ واحد
· PvP: ۲-۴ واحد
· استفاده از مهارت ویژه: ۵ واحد

آیتم‌های با کیفیت بالاتر Durability بیشتری دارند و دیرتر می‌شکنند.

آیتم‌های فوق‌نایاب:

· کیف نامحدود (Boundless Pouch): فقط ۱ عدد در کل سرور. هر تعداد آیتم می‌توان برد دانجن. در صورت مرگ، آیتم‌ها از دست نمی‌روند. غیرقابل فروش و تبادل (Bound).
· آیتم‌های اسطوره‌ای (Mythic): فقط ۵ عدد در کل سرور. قدرت‌های منحصر‌به‌فرد دارند. فقط از دانجن قرمز یا دروازه آزمایش دراپ می‌شوند.

۵. سیستم جمع‌آوری مانا (Mana Extraction)

توضیح:
بعد از تموم شدن هر دانجن، بازیکن ۹۰ ثانیه فرصت دارد ماناهای رها شده را جمع‌آوری کند.

Web App مخصوص:
یک صفحه ۴×۴ (۱۶ خانه) از کریستال‌های مانا نمایش داده می‌شود. بازیکن با توجه به ظرفیت کیف خود می‌تواند تعدادی را انتخاب کند.

انواع مانا:

· ⚪ مانای ضعیف: ارزش ۵۰ طلا
· 🔵 مانای خالص: ارزش ۲۰۰ طلا - قابل استفاده در کرفتینگ
· 🟣 مانای متمرکز: ارزش ۸۰۰ طلا - برای ارتقاء آیتم
· 🟡 مانای باستانی: ارزش ۳,۰۰۰ طلا - برای باز کردن دانجن مخفی
· 🔴 مانای فاسد: دام! اگر برداری -۵۰۰ طلا و آسیب به کاراکتر

ظرفیت کیف:

· کیف معمولی: ۳ اسلات
· کیف کمیاب: ۶ اسلات
· کیف حماسی: ۱۰ اسلات
· کیف افسانه‌ای: ۱۵ اسلات
· کیف نامحدود: برداشت نامحدود در ۹۰ ثانیه

مهارت ماناشناس: اگر یک ماناشناس در تیم باشد، ۳۰٪ مانای بیشتری استخراج می‌کند.

۶. سیستم گیلد (Guild System)

توضیح:
هر گپ تلگرامی می‌تواند به یک گیلد تبدیل شود.

فعال‌سازی:

· ادمین گپ: /register_guild → گپ به عنوان گیلد ثبت می‌شود
· اعضا: /join → عضو گیلد می‌شوند
· هر بازیکن فقط ۱ گیلد فعال می‌تواند داشته باشد
· تغییر گیلد: ۷ روز cooldown

مزایای گیلد:

· هر ۲۴ ساعت یک دانجن رایگان در گیلد اسپاون می‌شود
· مالک دانجن (اولین کسی که claim کند) می‌تواند خودش برود، با تیم برود، یا بفروشد (به اعضای گیلد یا بازار جهانی)
· دانجن قرمز فقط در گیلد اسپاون می‌شود
· اعضای گیلد کارمزد انتقال طلا ندارند

مقام‌بندی گیلد:
بر اساس مجموع قدرت اعضا و دانجن‌های فتح شده.

فروش دانجن:

```
محمد یک دانجن رنک A در گیلد "شکارچیان تهران" پیدا کرده و می‌فروشد به قیمت ۵,۰۰۰ طلا.
[دکمه خرید] [مشاهده جزئیات]
```

۷. سیستم تیمی (Party System)

توضیح:
برای دانجن‌های تیمی.

نقش‌ها:

· لیدر (سازنده تیم):
  · می‌تواند اعضا را Kick کند
  · دعوت‌ها را تأیید/رد کند
  · نوع تقسیم لوت را مشخص کند (مساوی یا بر اساس آسیب)
  · پس از بسته شدن تیم، فقط با رأی‌گیری می‌توان اعضا را حذف کرد
· اعضا:
  · می‌توانند قبل از شروع دانجن Leave دهند
  · بعد از شروع، Leave = مرگ در دانجن و از دست دادن آیتم‌های همراه

سیستم لوت:

· مساوی: همه به یک اندازه
· بر اساس آسیب: آسیب بیشتر = لوت بهتر
· لیدر انتخاب می‌کند

۸. سیستم سایه (Shadow System) - کاملاً مخفیانه

توضیح:
مهم‌ترین ویژگی مخفی بازی. همه تعاملات این سیستم فقط در پیوی ربات اتفاق می‌افتد و هیچ چیز در گروه فاش نمی‌شود.

تبدیل شدن به سایه:

· شرط: ۱۰۰ دانجن تموم شده، یا رسیدن به لول ۳۰، یا رویداد تصادفی (۱٪ شانس بعد از هر دانجن)
· پیام مرموز در پیوی:

⚫ ...احساس می‌کنی سایه‌ای تو ذهنت زمزمه می‌کنه...
"می‌خوای قدرتی فراتر از شکارچی‌های معمولی داشته باشی؟"
"قدرت واقعی... در تاریکیه."

🌑 یک فرصت مرموز پیش روته.
[🔥 قبول میکنم] [🙅 رد میکنم]

منطقه سایه (Shadow Zone) - منوی مخفی در پیوی:

```
⚫ منطقه سایه ⚫
━━━━━━━━━━━━━━━━
👁️ رصد دانجن‌های فعال...
🎯 انتخاب هدف برای Invade
🏴 دانجن سیاه (هفتگی)
💀 قربانی‌های اخیر تو
📊 رتبه سایه تو
⚙️ تنظیمات سایه
━━━━━━━━━━━━━━━━
⚠️ هشدار: Bounty تو: ۳,۵۰۰ طلا
```

سیستم Invade (PvPvE):

1. سایه وارد منوی "رصد دانجن‌های فعال" می‌شود
2. لیست دانجن‌هایی که هم‌اکنون بازیکنان در آن هستند نمایش داده می‌شود (بدون نام بازیکنان)
   · فقط: "دانجن رنک A | تیم ۳ نفره | ۱۲ دقیقه از شروع گذشته"
3. سایه یک دانجن را انتخاب و Invade می‌کند
4. برای تیم شکارچی، پیام در پیوی همه اعضا:

🚨 اخطار! حضور شوم حس می‌شود...
یه سایه به دانجن شما نفوذ کرده!
⚫ Shadow Invader ظاهر شده!

1. سایه به عنوان یک دشمن اضافه وارد مبارزه می‌شود
2. تیم باید هم با دشمنان دانجن بجنگد، هم با سایه

نتایج Invade:

· 🏆 سایه برنده: همه لوت تیم + طلای آنها را می‌دزدد
· 🛡️ تیم برنده: جایزه ویژه + طلای Bounty سایه را می‌گیرند

محدودیت Invade: ۳ بار در روز

سیستم Bounty (شکار جایزه‌دار):

· هر Invade موفق = Bounty (جایزه روی سر) سایه افزایش می‌یابد
· شکارچی‌ها می‌توانند در تابلوی Bounty (پیوی خودشان) سایه‌ها را ببینند:

💀 Bounty #۴۷ - سایه ناشناس | ۱۲ قربانی | جایزه: ۵,۲۰۰ طلا + آیتم افسانه‌ای

· شکارچی‌ها می‌توانند Tracker از شاپ بخرند (آیتمی که نشان می‌دهد سایه کی آنلاین است)
· وقتی سایه Invade می‌کند → شکارچی می‌تواند Counter-Invade کند (وارد همان دانجن شود و با سایه بجنگد)

لو رفتن هویت:

· اگر Bounty سایه از حدی بالاتر رود، شکارچیان رنک S و National می‌توانند هویت واقعی سایه را ببینند
· می‌توانند نام او را در بازار جهانی فاش کنند

۹. سیستم مرگ و بیداری سایه (Shadow Rebirth)

توضیح:
وقتی یک سایه در Invade یا Counter-Hunt می‌میرد، کاراکترش برای همیشه نابود نمی‌شود. در عوض، یک تولد دوباره (Rebirth) را تجربه می‌کند.

پیام مرگ سایه (فقط پیوی):

چه چیزهایی حفظ می‌شود:

قدرت بیداری - شروع جدید با قدرت بیشتر:

۱۰. سیستم شاپ و بازار (Shop & Market)

توضیح:
بازی دو بازار مجزا دارد که هر دو در Web App پیاده‌سازی می‌شوند.

---

بازار اول: شاپ عادی (Marketplace)

Web App شاپ:

صفحه اصلی بازار با دسته‌بندی‌های زیر:

· ⚔️ سلاح‌ها
· 🛡️ زره‌ها
· 🧪 معجون‌ها
· 📜 دستور پخت‌ها
· 💎 مانا
· 🎒 کیف‌ها

قیمت‌گذاری خودکار بر اساس عرضه و تقاضا:

الگوریتم:

```
اگر تقاضا > ۲ × عرضه → قیمت +۳۰٪
اگر تقاضا > ۱.۵ × عرضه → قیمت +۱۵٪
اگر عرضه > ۲ × تقاضا → قیمت -۲۵٪
اگر عرضه > ۱.۲۵ × تقاضا → قیمت -۱۰٪
```

ویژگی‌های شاپ:

· جستجوی آیتم با نام
· فیلتر بر اساس کیفیت، نوع، لول
· مرتب‌سازی بر اساس قیمت، محبوبیت، جدیدترین
· تاریخچه قیمت (نمودار ساده)

---

بازار دوم: بورس آیتم‌ها (Item Exchange)

مفهوم:
بازیکنان می‌توانند آیتم‌ها را مثل سهام معامله کنند. قیمت‌ها هر ۵ ثانیه بر اساس عرضه و تقاضا آپدیت می‌شوند. هدف: کم بخر، گرون بفروش!

نمادهای معاملاتی:

```
⚔️ SWD/طل  = شمشیر آتشین
🛡️ ARM/طل  = زره پادشاه
🧪 POT/طل  = معجون عمر
💎 MNA/طل  = کریستال مانا
🎒 BAG/طل  = کیف شکارچی
```

کندل ۵ ثانیه‌ای:
هر کندل شامل:

· Open (قیمت شروع)
· High (بالاترین قیمت)
· Low (پایین‌ترین قیمت)
· Close (قیمت پایان)
· Volume (حجم معاملات)

در ۲۴ ساعت = ۱۷,۲۸۰ کندل تشکیل می‌شود.

تایم‌فریم‌های نمودار:

· ⚡ ۵ ثانیه (Scalping)
· ⏱️ ۳۰ ثانیه
· 📊 ۱ دقیقه
· 📈 ۵ دقیقه (Position Trading)

انواع سفارشات:

۱. Market Order (سفارش لحظه‌ای):

· خرید/فروش با بهترین قیمت موجود در بازار
· اجرای فوری
· کارمزد: ۰.۱٪

۲. Limit Order (سفارش محدود):

· "اگه قیمت به X رسید، Y تا بخر/بفروش"
· تا ۴۸ ساعت اعتبار دارد
· کارمزد: ۰.۰۵٪

۳. Stop Loss (حد ضرر):

· "اگه قیمت به X رسید، همه رو بفروش"
· برای جلوگیری از ضرر بیشتر
· اجرای خودکار

۴. OCO (One Cancels Other):

· سفارش فروش در قیمت بالا + استاپ لاس در قیمت پایین
· هرکدام زودتر فعال شود، دیگری لغو می‌شود

سیستم اهرم (Leverage):

اهرم مارجین مورد نیاز سود/ضرر قیمت لیکویید شدن
۱x ۱۰۰٪ سرمایه معمولی ندارد
۲x ۵۰٪ سرمایه ۲ برابر -۵۰٪
۵x ۲۰٪ سرمایه ۵ برابر -۲۰٪
۱۰x ۱۰٪ سرمایه ۱۰ برابر -۱۰٪

مثال با اهرم ۵x:

· سرمایه: ۱۰۰,۰۰۰ طلا
· قدرت خرید: ۵۰۰,۰۰۰ طلا
· اگر قیمت +۱۰٪ شود → سود ۵۰,۰۰۰ طلا (۵۰٪ سود روی سرمایه!)
· اگر قیمت -۲۰٪ شود → لیکویید (از دست دادن تمام ۱۰۰,۰۰۰)

اندیکاتورهای تکنیکال روی نمودار:

· RSI (شاخص قدرت نسبی): RSI > 70 = اشباع خرید، RSI < 30 = اشباع فروش
· MACD: تشخیص روند صعودی/نزولی
· Volume: حجم معاملات در هر کندل
· Support/Resistance: خطوط حمایت و مقاومت خودکار

نوتیفیکیشن‌های معاملاتی (در پیوی ربات):

· 📈 تغییر قیمت +۵٪ در ۱ دقیقه
· 🎯 لیمیت اوردر پر شد
· ⚠️ مارجین کال (موجودی به ۵۰٪ مارجین لازم رسید)
· 💀 لیکویید شدن
· 🛡️ استاپ لاس فعال شد

محدودیت‌های بازار:

· Circuit Breaker: نوسان ±۱۰٪ در ۱ دقیقه → بازار ۵ دقیقه بسته می‌شود
· حداکثر اهرم: ۱۰x
· حداکثر حجم معامله: ۵۰۰ قرارداد در ۵ دقیقه (برای جلوگیری از دستکاری نهنگ‌ها)
· Anti-Wash Trading: خرید و فروش همزمان توسط یک نفر ممنوع

مسابقات ترید:

· هفتگی: بیشترین سود درصدی
· لیگ ماهانه:
  · 🥉 برنز: سود +۱۰٪
  · 🥈 نقره: سود +۲۵٪
  · 🥇 طلا: سود +۵۰٪
  · 👑 افسانه‌ای: سود +۱۰۰٪

۱۲. سیستم واسطه‌گری (Consignment System)

توضیح:
بازیکنان می‌توانند واسطه شوند و آیتم‌های دیگران را بفروشند.

انبار واسطه:
قابل ارتقاء با سطوح مختلف:

جایگاه اسلات کارمزد پایه مزایا
🥉 معمولی ۱۰ ۱۵٪ -
🥈 نقره‌ای ۲۵ ۱۲٪ +آمار هفتگی فروش
🥇 طلایی ۵۰ ۱۰٪ +نمودار قیمت
💎 الماسی ۱۰۰ ۸٪ +قیمت‌گذاری خودکار
👑 امپراتوری ۲۰۰ ۵٪ +فروشگاه اختصاصی

فرآیند واسطه‌گری:

۱. شکارچی آیتم خود را با قیمت درخواستی به واسطه می‌دهد
۲. واسطه قبول یا رد می‌کند
۳. اگر قبول کرد، کارمزد خود را تعیین می‌کند (مثلاً ۱۰٪)
۴. قیمت نهایی در فروشگاه واسطه = قیمت درخواستی + کارمزد
۵. واسطه آیتم را در فروشگاه خود لیست می‌کند
۶. خریدار می‌بیند: "توسط: محمد | کارمزد واسطه: ۸٪"
۷. پس از فروش: شکارچی ۹۰٪، واسطه ۱۰٪

ارتقاء انبار واسطه:

· اسلات بیشتر: ۵۰ ← ۱۰۰ (💎 ۲۰۰ گوهر)
· زمان نگهداری طولانی‌تر: ۷ ← ۱۴ روز (💎 ۱۵۰ گوهر)
· بیمه آیتم (در صورت هک یا باگ): 💎 ۳۰۰ گوهر ماهانه

· Backend ربات: TypeScript با کتابخانه grammy روی Cloudflare Workers
· Web App: Svelte/SvelteKit روی Cloudflare Pages
· API Server: Cloudflare Workers با TypeScript
· Database: Turso (SQLite) با Drizzle ORM

· File Storage: Cloudflare R2

۱. سیستم کاراکتر (Character System)

توضیح:
هر بازیکن با دستور /start یک کاراکتر می‌سازد. کاراکتر دارای استت‌های زیر است:

· ATK (قدرت حمله): میزان آسیب وارده به دشمن
· DEF (دفاع): کاهش آسیب دریافتی
· SPD (سرعت): تعیین نوبت حمله در فایت تیمی
· CRIT (شانس ضربه بحرانی): درصد احتمال آسیب ۲ برابر
· HEAL (بازیابی): مقدار سلامتی که می‌تواند در حین فایت بازیابی کند

بازیکن با کسب XP از دانجن‌ها لول آپ می‌شود. هر لول ۵ استت پوینت به بازیکن می‌دهد که می‌تواند بین استت‌هایش تقسیم کند. حداکثر لول ۱۰۰ است.

منوهای مورد نیاز:

· منوی پروفایل (نمایش استت‌ها، لول، XP، رنک)
· منوی تخصیص استت پوینت
· منوی تاریخچه دستاوردها

رنک‌بندی شکارچیان:

رنک عنوان مزایا
E شکارچی تازه‌کار بدون مزایا
D شکارچی کارآموز +۵٪ طلا از دانجن‌ها
C شکارچی حرفه‌ای +۱۰٪ طلا، ۱ اسلات کیف اضافه
B شکارچی کهنه‌کار +۱۵٪ طلا، اولویت در لوت تیمی
A شکارچی نخبه +۲۰٪ طلا، امکان ورود به دانجن قرمز
S شکارچی افسانه‌ای +۳۰٪ طلا، یک مهارت ویژه
National شکارچی ملی دسترسی به دانجن‌های ملی، فقط ۵ نفر در کل سرور

ارتقاء رنک بر اساس مجموع دانجن‌های تموم شده، قدرت کاراکتر و دستاوردهای خاص انجام می‌شود.

۲. سیستم دانجن (Dungeon System)

توضیح:
دانجن‌ها هسته اصلی بازی هستند. هر دانجن دارای لول (E تا S) و تعداد مشخصی موج دشمن (۳ تا ۱۰ موج) و یک باس نهایی است.

حالت‌های دانجن:

· سولو: بازیکن به تنهایی وارد می‌شود
· تیمی: لیدر تیم یک گروه می‌سازد، اعضا جوین می‌شوند، لیدر می‌تواند Kick کند یا دعوت‌ها را تأیید/رد کند. اعضا می‌توانند قبل از شروع Leave دهند. بعد از شروع، Leave = مرگ در دانجن. حداکثر ۵ نفر در تیم.

انواع دانجن:

الف) دانجن معمولی:

· لول‌بندی شده از E تا S
· دشمنان متناسب با لول دانجن
· دراپ آیتم و طلا پس از اتمام

ب) دانجن قرمز (Red Gate):

· شانس ۱-۲٪ ظاهر شدن در گیلد
· دشمنان +۱۰ لول قوی‌تر از قوی‌ترین عضو
· غیرقابل فرار - یا برنده می‌شوی یا می‌میری
· برد = یک لول کامل آپ (حتی از ۴۰ به ۴۱)
· دراپ فوق‌العاده کمیاب (مثل کیف نامحدود، آیتم اسطوره‌ای)
· فقط تیمی (حداقل ۳ نفر)

ج) دانجن مخفی (Hidden Dungeon):

· شانس ۵-۱۰٪ بعد از تموم شدن هر دانجن
· بازیکن ۳۰ ثانیه فرصت دارد تصمیم بگیرد وارد شود یا خیر (در حالت تیمی، رأی‌گیری اکثریت)
· ۵ نوع گذرگاه مخفی:
  ۱. اتاق شانس (۴۰٪): فقط مانا و گنج، بدون مبارزه
  ۲. کمین نخبگان (۳۵٪): ۲-۳ ماب نخبه، لوت ۲ برابر، بدون فرار
  ۳. هزارتوی فراموشی (۱۵٪): ۳ مسیر با انتخاب (گنج، تله ۵۰٪ آسیب، یا معما)
  ۴. اتاق کهن (۸٪): یک معمای سخت (چیستان، دنباله اعداد، رمزگشایی)، حل = آیتم افسانه‌ای یا کلید دانجن قرمز، اشتباه = از دست دادن ۱ آیتم تصادفی
  ۵. دروازه آزمایش (۲٪): چالش مرگ و زندگی

د) دروازه آزمایش (Gate of Trial):

· فقط ماهی یک بار در کل سرور ظاهر می‌شود
· فقط یک نفر می‌تواند وارد شود (اولین کسی که پیدا کند و قبول کند)
· شرط ورود: قربانی کردن تمام آیتم‌ها و طلای همراه
· ریسک: Permadeath واقعی (حتی Rebirth سایه هم نیست - کاراکتر کاملاً حذف می‌شود)
· فقط سولو

مراحل دروازه آزمایش:

1. هزارتوی سکوت: ۳ معمای منطقی/ریاضی سخت، ۲ دقیقه برای هر کدام، هر اشتباه = -۲۰٪ HP دائمی
2. آینه روح: مبارزه با کپی خود بازیکن (همان لول، استت و مهارت‌ها)
3. نگهبان دروازه (باس نهایی): ۱۰ لول بالاتر از بازیکن، ۳ مرحله با قدرت فزاینده، بدون امکان هیل بین مراحل

پیروزی = Divine Awakening:

· لول جدید: ۳۰ (یا ۲۰+ لول قبلی، هرکدام بیشتر)
· عنوان: "خداکُش" (Godslayer) با افکت طلایی روی اسم
· ۱۰۰ استت پوینت اضافه
· یک مهارت منحصر‌به‌فرد که فقط ۱ نفر در کل بازی دارد
· اسلات کیف: ۱۵ دائمی
· مقاومت ۵۰٪ به همه آسیب‌ها
· پیام جهانی (ناشناس): "یکی از شکارچیان... از دروازه آزمایش بازگشته است."

شکست:

· کاراکتر کاملاً حذف می‌شود
· نام در تالار قهرمانان فراموش‌شده ثبت می‌شود
· پیام در گیلد: "شکارچی [اسم] در جستجوی قدرت نهایی، جان خود را فدا کرد."

۳. سیستم مبارزه (Combat System)

توضیح:
مبارزه به صورت نوبتی است. بازیکن در هر نوبت یکی از گزینه‌های زیر را انتخاب می‌کند:

· 🗡️ حمله عادی: آسیب پایه بر اساس ATK
· 🔥 مهارت ویژه: آسیب بیشتر یا اثر خاص (بستگی به مهارت‌های بازیکن دارد)
· 🛡️ دفاع: کاهش ۵۰٪ آسیب دریافتی در آن نوبت
· 🧪 معجون: استفاده از آیتم مصرفی (هیل، تقویت موقت)
· 🏃 فرار: خروج از دانجن (در دانجن قرمز و بعضی مخفی‌ها غیرممکن)

نوار سلامتی (HP Bar):
با ایموجی قلب نمایش داده می‌شود:

```
❤️❤️❤️❤️❤️🤍🤍🤍🤍🤍  [50%]
```

در فایت تیمی:

· نوبت‌ها بر اساس SPD (سرعت) تعیین می‌شود
· سیستم Threat: بازیکنی که بیشترین آسیب را زده، بیشتر مورد حمله دشمن قرار می‌گیرد
· تانک‌ها (DEF بالا) مهارت "تحریک" دارند که Threat را افزایش می‌دهد

Web App فایت:

· صحنه مبارزه با انیمیشن‌های ساده (CSS animations)
· نوار HP با transition های نرم
· لاگ مبارزه (چه کسی چه آسیبی زد)
· دکمه‌های بزرگ و واکنش‌گرا
· گیف‌های کوتاه برای حملات خاص (از Cloudflare R2 لود شود)

۴. سیستم آیتم‌ها (Item System) - ۷۲۵+ آیتم

توضیح:
آیتم‌ها با سیستم Base + Prefix + Suffix ساخته می‌شوند تا تنوع بسیار بالا ایجاد شود.

آیتم‌های پایه (Base Items):
۱۰ نوع: شمشیر، خنجر، تبر، نیزه، سپر، زره، کلاه، دستکش، چکمه، عصا
هر کدام استت‌های پایه متفاوت دارند.

پیشوندها (Prefixes - عنصری):
۸ نوع:

· آتشین 🔥: +۱۰ آسیب آتش
· یخی ❄️: +۱۰ آسیب یخ، شانس کُند کردن دشمن
· برقی ⚡: +۱۰ آسیب برق، شانس استان
· سمی ☠️: +۸ آسیب سم در ۳ نوبت
· تاریک 🌑: +۱۵ آسیب (فقط برای سایه‌ها قابل استفاده)
· نورانی ✨: +۵ به همه استت‌ها
· خونین 🩸: ۵٪ Life Steal (درصدی از آسیب تبدیل به هیل)
· فرسوده 💀: -۵ قدرت، ولی شانس کریت +۱۵٪

پسوندها (Suffixes - منشأ):
۸ نوع:

· از گرگ 🐺: +۵٪ شانس کریت
· از اژدها 🐉: +۱۵٪ مقاومت آتش
· از فرشته 👼: +۱۰٪ قدرت هیل
· از شیطان 😈: +۲۰ ATK, -۱۰ DEF
· از پادشاه 👑: +۳ به همه استت‌ها
· از گورکن 💀: شانس ۵٪ زنده شدن پس از مرگ
· از معدن ⛏️: +۲۰٪ Durability
· از طبیعت 🌿: ۲٪ هیل خودکار در هر نوبت

فرمول: Base (۱۰) × Prefix (۸) × Suffix (۸) = ۶۴۰ ترکیب آیتم عادی

· ۵۰ آیتم خاص (افسانه‌ای و اسطوره‌ای)
· ۲۰ معجون مختلف
· ۱۵ کیف و اقلام مصرفی
  = ۷۲۵+ آیتم منحصر‌به‌فرد

کیفیت آیتم‌ها (Rarity):

· ⚪ معمولی (Common)
· 🔵 کمیاب (Rare)
· 🟣 حماسی (Epic)
· 🟡 افسانه‌ای (Legendary)
· 🔴 اسطوره‌ای (Mythic) - فقط ۱ تا ۵ عدد در کل سرور

سیستم Durability (سلامت آیتم):
هر آیتم یک نوار سلامت ۱۰۰ واحدی دارد:

وضعیت Durability اثر
✅ نو ۱۰۰-۸۰٪ قدرت کامل
⚠️ فرسوده ۷۹-۵۰٪ -۵٪ از قدرت کل
🔶 آسیب‌دیده ۴۹-۲۰٪ -۲۰٪ قدرت، +۱۰٪ شانس شکست در هر حمله
🔴 در حال شکستن ۱۹-۵٪ -۵۰٪ قدرت، ۳۰٪ شانس نابودی در هر حمله
💀 شکسته ۰٪ غیرقابل استفاده، فقط قابل تعمیر یا اسقاط

کاهش Durability:

· هر حمله در دانجن: ۱-۲ واحد
· باس فایت: ۳-۵ واحد
· PvP: ۲-۴ واحد
· استفاده از مهارت ویژه: ۵ واحد

آیتم‌های با کیفیت بالاتر Durability بیشتری دارند و دیرتر می‌شکنند.

آیتم‌های فوق‌نایاب:

· کیف نامحدود (Boundless Pouch): فقط ۱ عدد در کل سرور. هر تعداد آیتم می‌توان برد دانجن. در صورت مرگ، آیتم‌ها از دست نمی‌روند. غیرقابل فروش و تبادل (Bound).
· آیتم‌های اسطوره‌ای (Mythic): فقط ۵ عدد در کل سرور. قدرت‌های منحصر‌به‌فرد دارند. فقط از دانجن قرمز یا دروازه آزمایش دراپ می‌شوند.

۵. سیستم جمع‌آوری مانا (Mana Extraction)

توضیح:
بعد از تموم شدن هر دانجن، بازیکن ۹۰ ثانیه فرصت دارد ماناهای رها شده را جمع‌آوری کند.

Web App مخصوص:
یک صفحه ۴×۴ (۱۶ خانه) از کریستال‌های مانا نمایش داده می‌شود. بازیکن با توجه به ظرفیت کیف خود می‌تواند تعدادی را انتخاب کند.

انواع مانا:

· ⚪ مانای ضعیف: ارزش ۵۰ طلا
· 🔵 مانای خالص: ارزش ۲۰۰ طلا - قابل استفاده در کرفتینگ
· 🟣 مانای متمرکز: ارزش ۸۰۰ طلا - برای ارتقاء آیتم
· 🟡 مانای باستانی: ارزش ۳,۰۰۰ طلا - برای باز کردن دانجن مخفی
· 🔴 مانای فاسد: دام! اگر برداری -۵۰۰ طلا و آسیب به کاراکتر

ظرفیت کیف:

· کیف معمولی: ۳ اسلات
· کیف کمیاب: ۶ اسلات
· کیف حماسی: ۱۰ اسلات
· کیف افسانه‌ای: ۱۵ اسلات
· کیف نامحدود: برداشت نامحدود در ۹۰ ثانیه

مهارت ماناشناس: اگر یک ماناشناس در تیم باشد، ۳۰٪ مانای بیشتری استخراج می‌کند.

۶. سیستم گیلد (Guild System)

توضیح:
هر گپ تلگرامی می‌تواند به یک گیلد تبدیل شود.

فعال‌سازی:

· ادمین گپ: /register_guild → گپ به عنوان گیلد ثبت می‌شود
· اعضا: /join → عضو گیلد می‌شوند
· هر بازیکن فقط ۱ گیلد فعال می‌تواند داشته باشد
· تغییر گیلد: ۷ روز cooldown

مزایای گیلد:

· هر ۲۴ ساعت یک دانجن رایگان در گیلد اسپاون می‌شود
· مالک دانجن (اولین کسی که claim کند) می‌تواند خودش برود، با تیم برود، یا بفروشد (به اعضای گیلد یا بازار جهانی)
· دانجن قرمز فقط در گیلد اسپاون می‌شود
· اعضای گیلد کارمزد انتقال طلا ندارند

مقام‌بندی گیلد:
بر اساس مجموع قدرت اعضا و دانجن‌های فتح شده.

فروش دانجن:

```
محمد یک دانجن رنک A در گیلد "شکارچیان تهران" پیدا کرده و می‌فروشد به قیمت ۵,۰۰۰ طلا.
[دکمه خرید] [مشاهده جزئیات]
```

۷. سیستم تیمی (Party System)

توضیح:
برای دانجن‌های تیمی.

نقش‌ها:

· لیدر (سازنده تیم):
  · می‌تواند اعضا را Kick کند
  · دعوت‌ها را تأیید/رد کند
  · نوع تقسیم لوت را مشخص کند (مساوی یا بر اساس آسیب)
  · پس از بسته شدن تیم، فقط با رأی‌گیری می‌توان اعضا را حذف کرد
· اعضا:
  · می‌توانند قبل از شروع دانجن Leave دهند
  · بعد از شروع، Leave = مرگ در دانجن و از دست دادن آیتم‌های همراه

سیستم لوت:

· مساوی: همه به یک اندازه
· بر اساس آسیب: آسیب بیشتر = لوت بهتر
· لیدر انتخاب می‌کند

۸. سیستم سایه (Shadow System) - کاملاً مخفیانه

توضیح:
مهم‌ترین ویژگی مخفی بازی. همه تعاملات این سیستم فقط در پیوی ربات اتفاق می‌افتد و هیچ چیز در گروه فاش نمی‌شود.

تبدیل شدن به سایه:

· شرط: ۱۰۰ دانجن تموم شده، یا رسیدن به لول ۳۰، یا رویداد تصادفی (۱٪ شانس بعد از هر دانجن)
· پیام مرموز در پیوی:

⚫ ...احساس می‌کنی سایه‌ای تو ذهنت زمزمه می‌کنه...
"می‌خوای قدرتی فراتر از شکارچی‌های معمولی داشته باشی؟"
"قدرت واقعی... در تاریکیه."

🌑 یک فرصت مرموز پیش روته.
[🔥 قبول میکنم] [🙅 رد میکنم]

منطقه سایه (Shadow Zone) - منوی مخفی در پیوی:

```
⚫ منطقه سایه ⚫
━━━━━━━━━━━━━━━━
👁️ رصد دانجن‌های فعال...
🎯 انتخاب هدف برای Invade
🏴 دانجن سیاه (هفتگی)
💀 قربانی‌های اخیر تو
📊 رتبه سایه تو
⚙️ تنظیمات سایه
━━━━━━━━━━━━━━━━
⚠️ هشدار: Bounty تو: ۳,۵۰۰ طلا
```

سیستم Invade (PvPvE):

1. سایه وارد منوی "رصد دانجن‌های فعال" می‌شود
2. لیست دانجن‌هایی که هم‌اکنون بازیکنان در آن هستند نمایش داده می‌شود (بدون نام بازیکنان)
   · فقط: "دانجن رنک A | تیم ۳ نفره | ۱۲ دقیقه از شروع گذشته"
3. سایه یک دانجن را انتخاب و Invade می‌کند
4. برای تیم شکارچی، پیام در پیوی همه اعضا:

🚨 اخطار! حضور شوم حس می‌شود...
یه سایه به دانجن شما نفوذ کرده!
⚫ Shadow Invader ظاهر شده!

1. سایه به عنوان یک دشمن اضافه وارد مبارزه می‌شود
2. تیم باید هم با دشمنان دانجن بجنگد، هم با سایه

نتایج Invade:

· 🏆 سایه برنده: همه لوت تیم + طلای آنها را می‌دزدد

· شکارچی‌ها می‌توانند در تابلوی Bounty (پیوی خودشان) سایه‌ها را ببینند:

لو رفتن هویت:

بازار اول: شاپ عادی (Marketplace)

Web App شاپ:

قیمت‌گذاری خودکار بر اساس عرضه و تقاضا:

الگوریتم:

```
اگر تقاضا > ۲ × عرضه → قیمت +۳۰٪
اگر تقاضا > ۱.۵ × عرضه → قیمت +۱۵٪
اگر عرضه > ۲ × تقاضا → قیمت -۲۵٪
```

بازار دوم: بورس آیتم‌ها (Item Exchange)

مفهوم:
بازیکنان می‌توانند آیتم‌ها را مثل سهام معامله کنند. قیمت‌ها هر ۵ ثانیه بر اساس عرضه و تقاضا آپدیت می‌شوند. هدف: کم بخر، گرون بفروش!

نمادهای معاملاتی:

```
⚔️ SWD/طل  = شمشیر آتشین
🛡️ ARM/طل  = زره پادشاه
🧪 POT/طل  = معجون عمر
💎 MNA/طل  = کریستال مانا
🎒 BAG/طل  = کیف شکارچی
```

کندل ۵ ثانیه‌ای:
هر کندل شامل:

· Open (قیمت شروع)
· High (بالاترین قیمت)
· Low (پایین‌ترین قیمت)
· Close (قیمت پایان)
· Volume (حجم معاملات)

در ۲۴ ساعت = ۱۷,۲۸۰ کندل تشکیل می‌شود.

تایم‌فریم‌های نمودار:

· ⚡ ۵ ثانیه (Scalping)
· ⏱️ ۳۰ ثانیه
· 📊 ۱ دقیقه
· 📈 ۵ دقیقه (Position Trading)

انواع سفارشات:

۱. Market Order (سفارش لحظه‌ای):

· خرید/فروش با بهترین قیمت موجود در بازار
· اجرای فوری
· کارمزد: ۰.۱٪

۲. Limit Order (سفارش محدود):

· "اگه قیمت به X رسید، Y تا بخر/بفروش"
· تا ۴۸ ساعت اعتبار دارد
· کارمزد: ۰.۰۵٪

۳. Stop Loss (حد ضرر):

· "اگه قیمت به X رسید، همه رو بفروش"
· برای جلوگیری از ضرر بیشتر
· اجرای خودکار

۴. OCO (One Cancels Other):

· سفارش فروش در قیمت بالا + استاپ لاس در قیمت پایین
· هرکدام زودتر فعال شود، دیگری لغو می‌شود

سیستم اهرم (Leverage):

اهرم مارجین مورد نیاز سود/ضرر قیمت لیکویید شدن
۱x ۱۰۰٪ سرمایه معمولی ندارد
۲x ۵۰٪ سرمایه ۲ برابر -۵۰٪
۵x ۲۰٪ سرمایه ۵ برابر -۲۰٪
۱۰x ۱۰٪ سرمایه ۱۰ برابر -۱۰٪

مثال با اهرم ۵x:

· سرمایه: ۱۰۰,۰۰۰ طلا
· قدرت خرید: ۵۰۰,۰۰۰ طلا
· اگر قیمت +۱۰٪ شود → سود ۵۰,۰۰۰ طلا (۵۰٪ سود روی سرمایه!)
· اگر قیمت -۲۰٪ شود → لیکویید (از دست دادن تمام ۱۰۰,۰۰۰)

اندیکاتورهای تکنیکال روی نمودار:

· RSI (شاخص قدرت نسبی): RSI > 70 = اشباع خرید، RSI < 30 = اشباع فروش
· MACD: تشخیص روند صعودی/نزولی
· Volume: حجم معاملات در هر کندل
· Support/Resistance: خطوط حمایت و مقاومت خودکار

نوتیفیکیشن‌های معاملاتی (در پیوی ربات):

· 📈 تغییر قیمت +۵٪ در ۱ دقیقه
· 🎯 لیمیت اوردر پر شد
· ⚠️ مارجین کال (موجودی به ۵۰٪ مارجین لازم رسید)
· 💀 لیکویید شدن
· 🛡️ استاپ لاس فعال شد

محدودیت‌های بازار:

· Circuit Breaker: نوسان ±۱۰٪ در ۱ دقیقه → بازار ۵ دقیقه بسته می‌شود
· حداکثر اهرم: ۱۰x
· حداکثر حجم معامله: ۵۰۰ قرارداد در ۵ دقیقه (برای جلوگیری از دستکاری نهنگ‌ها)
· Anti-Wash Trading: خرید و فروش همزمان توسط یک نفر ممنوع

مسابقات ترید:

· هفتگی: بیشترین سود درصدی
· لیگ ماهانه:
  · 🥉 برنز: سود +۱۰٪
  · 🥈 نقره: سود +۲۵٪
  · 🥇 طلا: سود +۵۰٪
  · 👑 افسانه‌ای: سود +۱۰۰٪

۱۲. سیستم واسطه‌گری (Consignment System)

توضیح:

انبار واسطه:

جایگاه اسلات کارمزد پایه مزایا
🥉 معمولی ۱۰ ۱۵٪ -
🥈 نقره‌ای ۲۵ ۱۲٪ +آمار هفتگی فروش

فرآیند واسطه‌گری:

۱. شکارچی آیتم خود را با قیمت درخواستی به واسطه می‌دهد
۲. واسطه قبول یا رد می‌کند
۳. اگر قبول کرد، کارمزد خود را تعیین می‌کند (مثلاً ۱۰٪)

۶. خریدار می‌بیند: "توسط: محمد | کارمزد واسطه: ۸٪"
۷. پس از فروش: شکارچی ۹۰٪، واسطه ۱۰٪

· اسلات بیشتر: ۵۰ ← ۱۰۰ (💎 ۲۰۰ گوهر)
· زمان نگهداری طولانی‌تر: ۷ ← ۱۴ روز (💎 ۱۵۰ گوهر)

۲. تولید تصادفی نقشه (Procedural Dungeon Generation)

نقشه باید هر بار که بازیکن وارد دانجن می‌شود، کاملاً تصادفی تولید شود.

الگوریتم: ترکیبی از Drunkard's Walk (برای راهروها) و Room Placement (برای اتاق‌ها)

مشخصات فنی:

· ابعاد نقشه: متغیر بر اساس لول بازیکن (حداقل ۵۰×۵۰، حداکثر ۱۵۰×۱۵۰ تایل)
· سایز هر تایل: ۳۲×۳۲ پیکسل
· نقشه شامل:
  · راهروها (Corridors): مسیرهای اصلی با عرض ۱-۳ تایل
  · اتاق‌ها (Rooms): فضاهای باز با ابعاد مختلف (۳×۳ تا ۸×۸ تایل)

انواع اتاق‌ها:

1. اتاق شروع (Start Room): جایی که بازیکن وارد می‌شود و دروازه خروج همینجاست. امن، بدون دشمن. یک شعله نورانی وسط اتاق.
2. اتاق باس (Boss Room): دورترین اتاق از نقطه شروع. بزرگترین اتاق (۶×۶ تا ۸×۸). باس اینجا منتظر است.
3. اتاق گنج (Treasure Room): ۱-۲ عدد در نقشه. اتاق‌های بن‌بست پر از کریستال مانا و یک صندوقچه. بدون دشمن.
4. اتاق تله (Trap Room): ۱-۲ عدد. ظاهر عادی دارند ولی وقتی بازیکن وارد می‌شود، در بسته می‌شود و تله فعال می‌شود (کف فرو ریزنده، گاز سمی، دیوارهای نزدیک‌شونده).
5. اتاق مخفی (Secret Room): ۰-۱ عدد. پشت یک دیوار قابل تخریب. در Minimap دیده نمی‌شود مگر بازیکن دیوار را بشکند (Attack روی دیوار ترک‌خورده).
6. اتاق معما (Puzzle Room): ۰-۱ عدد. یک پازل ساده (سه اهرم با ترتیب درست). حل پازل = باز شدن راه به یک گنج بزرگ.
7. اتاق استراحت (Rest Room): ۱ عدد. امن، بدون دشمن و تله. بازیکن می‌تواند نفس بگیرد و آیتم‌هایش را بررسی کند.

راهروها:

· عادی (۷۰٪): ۱-۲ ماب کوچک
· خطرناک (۱۵٪): پر از تله (کف فرو ریزنده، گاز سمی)
· مانا (۱۵٪): دیوارها کریستال مانا دارند، بدون دشمن

مسیرهای چندشاخه:

· بازیکن باید ۲-۳ بار در طول دانجن به دوراهی یا سه‌راهی برسد
· هر مسیر به نوع متفاوتی ختم می‌شود (گنج، نبرد، بن‌بست، تله)

۳. سیستم Fog of War (مه جنگ)

مفهوم: کل نقشه تاریک است. بازیکن فقط اطراف خود را می‌بیند.

سه لایه شفافیت:

1. منطقه دید (Visible):
   · اطراف بازیکن تا شعاع ۵ تایل (۱۶۰ پیکسل)
   · کاملاً روشن و واضح
   · دشمنان، تله‌ها، کریستال‌ها دیده می‌شوند
2. منطقه کشف شده (Explored):
   · جاهایی که بازیکن قبلاً رفته
   · نیمه‌شفاف و خاکستری (opacity ۵۰٪)
   · ساختار کلی (دیوارها، کف) دیده می‌شود
   · دشمنان و آیتم‌ها دیگر دیده نمی‌شوند (مگر بازیکن برگردد)
3. منطقه ناشناخته (Unexplored):
   · کاملاً سیاه
   · هیچ چیز دیده نمی‌شود

پیاده‌سازی فنی:

· استفاده از RenderTexture در Phaser
· یک آرایه ۲ بعدی exploredMap[height][width] با مقادیر ۰ (ناشناخته)، ۱ (کشف شده)، ۲ (در دید)
· به‌روزرسانی در هر فریم (۶۰fps)
· برای performance: فقط تایل‌هایی که تغییر کرده‌اند را آپدیت کن

۴. هوش مصنوعی دشمنان (Enemy AI)

دشمنان باید سه لایه رفتار داشته باشند:

لایه ۱: رفتار پایه (Idle/Patrol)

ماب‌های معمولی:

· حرکت در مسیر ثابت (Patrol) با سرعت کم
· میدان دید محدود: مخروط ۱۲۰ درجه، شعاع ۱۵۰ پیکسل
· اگر بازیکن وارد میدان دید شود → لایه ۲ فعال می‌شود
· اگر بازیکن پشت سر باشد (خارج از مخروط دید) → دشمن متوجه نمی‌شود! (Stealth ممکن است)
· وقتی بازیکن را گم کند → ۵ ثانیه تعقیب، سپس برمی‌گردد سر پست قبلی

باس:

· در مرکز اتاق خود منتظر می‌ماند
· میدان دید ۳۶۰ درجه (همه جهات)
· هر ۲۰-۳۰ ثانیه یک غرش (صوتی) - هشدار به بازیکن که باس نزدیک است

لایه ۲: تعقیب و حمله (Chase/Attack)

ماب‌های معمولی:

· **Pathfinding A\*** برای پیدا کردن مسیر به سمت بازیکن
· سرعت تعقیب: کمی کمتر از سرعت بازیکن (بازیکن می‌تواند فرار کند)
· محدودیت تعقیب: اگر بازیکن از میدان دید خارج شود → ۵ ثانیه تعقیب در همان جهت → اگر پیدا نشد، برمی‌گردد
· هر ۱-۲ ثانیه حمله اگر در range باشد (فاصله < ۵۰ پیکسل)

باس - سه فاز:

فاز ۱ (۱۰۰-۷۰٪ HP):

· حملات کند و سنگین با تلگراف (پیش‌نمایش) - بازیکن می‌تواند Dodge کند
· یک دایره قرمز روی زمین ۰.۵ ثانیه قبل از حمله نشان داده می‌شود
· Pattern: حمله → ۲ ثانیه استراحت → حمله
· هر ۱۵ ثانیه یک Ground Slam: آسیب منطقه‌ای به شعاع ۱۰۰ پیکسل، بازیکن باید عقب برود

فاز ۲ (۶۹-۳۰٪ HP):

· حالت خشم: چشم‌ها قرمز، افکت آتش دور بدن، سرعت ۵۰٪ بیشتر
· Pattern: ۳ حمله پشت سر هم → ۱ ثانیه استراحت
· حمله جدید - Charge: باس با سرعت زیاد به سمت بازیکن می‌دود (مسافت ۲۰۰ پیکسل). بازیکن باید سریع جاخالی بدهد.
· احضار مینیون: هر ۲۰ ثانیه، ۲-۳ ماب کوچک احضار می‌کند

فاز ۳ (۲۹-۰٪ HP):

· حالت ناامیدی (Desperation): خطرناک‌ترین فاز
· کل اتاق با آتش یا سم پر می‌شود (DOT - Damage Over Time، هر ثانیه ۵٪ HP)
· Pattern: حملات بی‌وقفه، بدون استراحت
· حمله Ultimate: هر ۱۰ ثانیه، آسیب ۵۰٪ HP بازیکن (اگر نخورد)
· بازیکن باید سریع باس را تمام کند

لایه ۳: رفتار هوشمند (Smart Behavior)

1. Call for Help: اگر ماب ۵۰٪ HP از دست بدهد، فریاد می‌زند. ماب‌های دیگر در شعاع ۳۰۰ پیکسل به کمک می‌آیند.
2. Ambush (کمین): بعضی ماب‌ها در اتاق‌های تاریک پنهان می‌شوند. وقتی بازیکن وارد می‌شود → در بسته می‌شود → ۳-۴ ماب از تاریکی حمله می‌کنند.
3. Flanking (حمله جانبی): دو ماب باهم همکاری می‌کنند: یکی از جلو حمله می‌کند (توجه بازیکن را جلب می‌کند)، دیگری از بغل دور می‌زند.
4. Retreat and Heal: اگر ماب زیر ۲۰٪ HP برود، عقب‌نشینی می‌کند و به اتاق استراحت می‌رود تا هیل شود. بازیکن باید تصمیم بگیرد: تعقیب کند یا نه؟
5. Boss Memory (حافظه باس): باس الگوی حمله بازیکن را یاد می‌گیرد:
   · اگر بازیکن زیاد Dodge می‌کند → باس به جای Charge، حمله منطقه‌ای (AOE) می‌کند
   · اگر بازیکن زیاد حمله می‌کند → باس حالت دفاعی می‌گیرد (سپر، کاهش ۵۰٪ آسیب)
   · اگر بازیکن از معجون استفاده می‌کند → باس حمله Silence می‌کند (آیتم‌ها ۵ ثانیه غیرفعال)
6. Environmental Usage: باس از محیط استفاده می‌کند:
   · ستون‌ها را خراب می‌کند (سقوط سنگ روی بازیکن)
   · گودال آتش ایجاد می‌کند (کنترل منطقه - بازیکن نمی‌تواند آنجا برود)
   · بازیکن را به تله‌های دیواری می‌کوبد (Stun ۲ ثانیه)

۵. سیستم مبارزه (Combat)

مشخصات:

· بازیکن دکمه حمله می‌زند → انیمیشن حمله اجرا می‌شود
· Cooldown حمله: ۰.۵ ثانیه (۳۰ فریم در ۶۰fps)
· Range حمله: ۵۰ پیکسل (نزدیک)
· آسیب: ATK بازیکن + random(-5, +5)
· Dodge: بازیکن با حرکت سریع (Double Tap) می‌تواند از حملات دشمن جاخالی دهد (۰.۳ ثانیه invincibility)
· معجون: استفاده از آیتم مصرفی (هیل ۵۰ HP، تقویت موقت ۱۰ ثانیه، و...). Cooldown: ۱۵ ثانیه
· فرار: خروج اضطراری از دانجن با جریمه (از دست دادن ۵۰٪ طلا و آیتم‌های جمع‌آوری شده)

وقتی دشمن می‌میرد:

· انیمیشن مرگ (fade out، scale to 0)
· دراپ لوت روی زمین:
  · آیتم تصادفی (بر اساس لول دانجن و شانس)
  · کریستال مانا (۱-۳ عدد)
  · طلا
· لوت به صورت Sprite درخشان روی زمین می‌ماند
· بازیکن باید با حرکت روی آن لوت را جمع کند (نه دکمه جداگانه)
· اگر Inventory پر باشد → پیام "کیفت پره! 📦" و آیتم روی زمین می‌ماند

۶. سیستم لوت و جمع‌آوری

Inventory بازیکن:

· ظرفیت محدود (بر اساس کیف: ۳ تا ۱۵ اسلات)
· نمایش با شمارنده در HUD: 📦 ۴/۸
· دسترسی سریع با Swipe از پایین به بالا (پنل Slide-up)

انواع لوت:

· ⚔️ آیتم‌های جنگی: سلاح، زره (با سیستم Base + Prefix + Suffix که قبلاً طراحی شده)
· 💎 کریستال مانا: ضعیف (۵۰ طلا)، خالص (۲۰۰)، متمرکز (۸۰۰)، باستانی (۳۰۰۰)، فاسد (دام! -۵۰۰ طلا)
· 📜 دستور پخت: نادر (شانس ۵٪)
· 💰 طلا: مستقیم به موجودی اضافه می‌شود

جمع‌آوری کریستال مانا:

· کریستال‌ها روی دیوارها و کف اتاق‌ها (به خصوص اتاق گنج و راهروهای مانا) قرار دارند
· بازیکن با نزدیک شدن (فاصله < ۴۰ پیکسل) به صورت خودکار جمع می‌کند
· انیمیشن: کریستال به سمت بازیکن fly می‌کند و ناپدید می‌شود
· مانای فاسد: ظاهرش شبیه مانای معمولی است ولی رنگ قرمز تیره دارد. اگر بازیکن جمع کند: -۵۰۰ طلا + آسیب ۱۰٪ HP + افکت مسمومیت (۵ ثانیه)

۷. تایمر و دروازه خروج

تایمر:

· هر دانجن یک زمان محدود دارد (بر اساس لول: ۳-۸ دقیقه)
· نمایش در HUD بالای صفحه: ⏱️ ۳:۴۵
· رفتار تایمر:
  · بالای ۲ دقیقه: سفید
  · ۱-۲ دقیقه: نارنجی
  · ۳۰-۶۰ ثانیه: قرمز + لرزش خفیف صفحه
  · زیر ۳۰ ثانیه: قرمز چشمک‌زن + لرزش قوی + صدای ضربان قلب

دروازه خروج:

· دروازه در اتاق شروع (همان جایی که بازیکن وارد شده) قرار دارد
· دروازه از ابتدا فعال نیست
· شرط فعال‌سازی: یا تمام دشمنان نقشه کشته شوند، یا ۲ دقیقه از زمان دانجن گذشته باشد
· وقتی فعال شد → دروازه شروع به درخشش می‌کند (انیمیشن نور)
· بازیکن باید خودش را به دروازه برساند و روی آن بایستد (فاصله < ۵۰ پیکسل) تا خارج شود
· اگر تایمر تمام شود قبل از رسیدن به دروازه → مرگ در دانجن (از دست دادن تمام آیتم‌های همراه)

استراتژی بازیکن:

· بازیکن باید زمان را مدیریت کند: چقدر جلو برود، چقدر برای برگشتن وقت بگذارد
· می‌تواند اول تا باس برود، بعد در راه برگشت گنج‌ها را جمع کند
· اگر وقت کم بیاورد، می‌تواند از دکمه فرار استفاده کند (با جریمه)

۸. طراحی رابط کاربری (UI/HUD)

صفحه بازی باید شامل موارد زیر باشد (همه نیمه‌شفاف با Glass Morphism):

نوار بالایی (Top Bar) - همیشه visible:

· نام دانجن: 🏚️ غار گابلین‌ها (فونت درشت، رنگ طلایی)
· تایمر: ⏱️ ۳:۴۵ (رفتار پویا - توضیح داده شد)
· HP: ❤️❤️❤️❤️🤍🤍 ۸۵٪ (قلب‌های تپنده)
· کیف: 📦 ۴/۸

طراحی: پس‌زمینه مشکی نیمه‌شفاف (opacity ۷۰٪) با blur (backdrop-filter). گوشه‌های گرد. فاصله از بالای صفحه ۱۰px.

Minimap (گوشه پایین چپ):

· ابعاد: ۱۵۰×۱۵۰ پیکسل
· دایره‌ای یا مربع با گوشه‌های گرد
· فقط جاهای کشف شده را نشان می‌دهد (Explored = خاکستری، Unexplored = سیاه)
· موقعیت فعلی بازیکن: نقطه سفید چشمک‌زن
· دروازه خروج: نماد 🚪 (همیشه روی Minimap هست، حتی اگر دور باشد)
· علامت سؤال (?): برای جاهایی که صدا شنیده شده (غرش باس از پشت دیوار)

Joystick (گوشه پایین وسط):

· نوع: Floating Joystick (هرجا بازیکن انگشتش را بگذارد، Joystick همانجا ظاهر می‌شود)
· دایره بیرونی: سفید با opacity ۳۰٪، قطر ۱۲۰px
· دایره داخلی (thumb): سفید با opacity ۷۰٪، قطر ۵۰px
· وقتی بازیکن thumb را می‌کشد، یک خط نازک جهت حرکت را نشان می‌دهد

دکمه‌های عمل (گوشه پایین راست):

· سه دکمه دایره‌ای (۶۰px قطر) به صورت ستونی:
  · ⚔️ حمله (بالا): پس‌زمینه قرمز تیره
  · 🧪 معجون (وسط): پس‌زمینه سبز تیره
  · 🏃 فرار (پایین): پس‌زمینه آبی تیره
· هر دکمه یک Cooldown indicator دارد (نوار دایره‌ای دور دکمه که پر می‌شود)

نشانگرهای روی نقشه (World Markers):

· ❗: دشمن نزدیک (در Fog of War) - fade in/out
· 💀: باس - جمجمه بزرگ، پالس قرمز
· 💎: کریستال مانا - درخشش آبی
· 🎁: صندوقچه - درخشش طلایی
· ⚠️: تله - علامت خطر (فقط وقتی خیلی نزدیکی)
· 🚪: دروازه خروج - درخشش سفید
· ❓: صدای مشکوک - علامت سؤال (نشان دهنده راه مخفی)

پنجره‌های Pop-up:

· ورود به اتاق جدید: نام اتاق + یک متن اتمسفریک کوتاه ("بوی مانا می‌ده...") - ۲ ثانیه نمایش، سپس fade out
· ظاهر شدن باس: نام باس با فونت بزرگ + HP bar + گزینه "آماده‌ام!" - صفحه dark می‌شود (vignette effect)
· لوت آیتم: کارت آیتم با انیمیشن (از زمین بلند می‌شود) + دکمه‌های "📦 بردار" و "🗑️ ولش کن"

۹. اتمسفر و Immersion

صدا (Audio):

· Ambient: صدای باد، چکیدن آب، نفس‌های هیولا از دور (loop)
· Footsteps: صدای قدم روی سنگ (با pitch random برای تنوع)
· Combat: صدای شمشیر (swing + hit)، غرش دشمن، انفجار
· UI: صدای کلیک ملایم برای دکمه‌ها
· موسیقی: موسیقی آرام در راهروها → موسیقی حماسی در اتاق باس
· هشدار: صدای ضربان قلب برای تایمر زیر ۳۰ ثانیه

نور (Lighting):

· Torch effect: دایره نور دور بازیکن (شعاع ۱۶۰px)
· راهروهای باریک: نور کمتر (darkness vignette)
· اتاق‌ها: نور بیشتر (مشعل روی دیوار)
· نزدیک باس: نور قرمز/بنفش
· نزدیک دروازه: نور طلایی/سفید

Vignette Effect:

· حاشیه‌های صفحه کمی تیره‌تر (حس نگاه از پشت ماسک)
· موقع آسیب دیدن → red vignette (flash)
· موقع استفاده از معجون → green flash
· موقع باس فایت → dark vignette (تمرکز روی مبارزه)

۱۰. ارتباط با ربات و API

قبل از ورود به دانجن (ربات):

· بازیکن دکمه "⚔️ دانجن" را در ربات می‌زند
· ربات لیست دانجن‌های موجود را نشان می‌دهد
· بازیکن یک دانجن را انتخاب می‌کند
· ربات یک دکمه "🔥 شروع مبارزه!" با web_app URL می‌فرستد
· URL شامل ?dungeon_id=XXX&player_id=YYY است

حین دانجن (Web App):

· Web App باز می‌شود
· از API اطلاعات دانجن (نقشه تولید شده، مشخصات بازیکن) را fetch می‌کند
· بازی اجرا می‌شود

بعد از دانجن (Web App → ربات):

· وقتی بازیکن از دروازه خارج می‌شود (یا می‌میرد، یا تایمر تمام می‌شود):
  ```javascript
  Telegram.WebApp.sendData(JSON.stringify({
    event: 'dungeon_complete',
    dungeon_id: 123,
    result: 'success', // or 'death', 'timeout', 'escape'
    enemies_killed: 15,
    loot: [
      { item_id: 45, quantity: 1 },
      { item_id: 12, quantity: 3 }
    ],
    mana_collected: 1500,
    gold_earned: 2500,
    xp_earned: 500,
    time_taken: 245 // ثانیه
  }));
  
  Telegram.WebApp.close();
  ```
· ربات web_app_data event را دریافت می‌کند
· ربات لوت را در دیتابیس ذخیره می‌کند
· ربات پیام "🎉 دانجن تموم شد!" با جزئیات لوت می‌فرستد

۱۲. Performance Optimization

· Object Pooling: برای دشمنان، کریستال‌ها و افکت‌ها از Object Pool استفاده کن (به جای destroy و create مداوم)
· Culling: فقط تایل‌هایی که در دید بازیکن هستند رندر شوند
· Fog of War Optimization: فقط تایل‌هایی که تغییر وضعیت داده‌اند آپدیت شوند
· Frame Rate: روی موبایل ۳۰fps، روی دسکتاپ ۶۰fps
· Texture Atlas: همه اسپرایت‌ها در یک atlas باشند (کاهش draw calls)
